# Bundled fonts

All fonts are shipped with the extension so the new tab page makes no font requests.
Files come from [Fontsource](https://fontsource.org) 5.3.0 (Inter: variable font with optical sizing; others: regular 400 weight; latin, latin-ext, cyrillic and cyrillic-ext subsets).
`@font-face` rules are in `styles/fonts.css`.
